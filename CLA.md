# Contributor Licence Agreement

Thank you for wanting to contribute to Hostzilla. Before your first pull request
can be merged, we need you to agree to the terms below.

## Why this exists — the honest version

Hostzilla is dual-licensed: [AGPL-3.0](LICENSE) for everyone, and a
[commercial licence](COMMERCIAL.md) for organisations that cannot accept the
AGPL's source-sharing obligations. Selling that commercial licence is how this
project is funded.

Offering a commercial licence is only legally possible if one party holds the
rights to the entire codebase. If contributions arrived under the AGPL alone,
every contributor would hold a veto over commercial licensing, and a single
unreachable contributor would end it permanently.

So this CLA is not a rights grab, and it is not there to take your work away
from you. **You keep full ownership and copyright of everything you write.** You
are granting a licence alongside your own rights, not instead of them.

We would rather tell you this plainly than bury it. If you are not comfortable
with it, that is a completely reasonable position — please open an issue instead
of a pull request, and we will still be glad of the help.

## How to sign

Add this line to each commit message:

```
Signed-off-by: Your Name <your.email@example.com>
```

`git commit -s` adds it for you.

On your first pull request, add one comment saying:

```
I have read the CLA and I agree to it.
```

That is all — once per contributor, not once per pull request.
